## Featured Project

### Machine Learning-Based Network Intrusion Detection System

Developed a Python-based intrusion detection prototype using the CICIDS2017 network-flow dataset. Compared Logistic Regression, Random Forest, tuned Random Forest, HistGradientBoosting, rule-based, and dummy baselines, with evaluation focused on attack precision, recall, F1-score, cross-validation, threshold tuning, and source-file holdout generalization.

**Key outcome:** HistGradientBoosting reached **0.9953 attack F1-score** on the random split and **0.7551 attack F1-score** under source-file holdout testing, highlighting both strong detection performance and realistic generalization limits.

**Technologies:** Python, pandas, NumPy, scikit-learn, SHAP, matplotlib, seaborn, Jupyter Notebook
